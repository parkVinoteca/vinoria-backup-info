プライバシーポリシー

対象：運営者専用ツール Vinoria Backup。Vinoriaアプリ本体の利用条件・プライバシーポリシーとは別の、Google Drive連携についての説明です。

取得・利用する情報

運営者が許可したGoogle Driveの認証トークンと、このツールが作成・使用するバックアップファイル、その識別子・更新情報・容量等を、バックアップ保存、復元確認、容量確認、保存期間に応じた整理に使用します。認証トークンは継続する自動処理のために保管します。

保存先と処理

バックアップの自動処理は非公開のGitHub Actions実行環境で行い、Google Driveには暗号化したデータを保存します。GitHubとGoogleをこの処理のために利用します。処理設備により日本国外で処理・保管される場合があります。処理中の一時ファイルは作業終了時に整理します。

利用の制限

Googleユーザーデータを販売したり、広告、利用者の追跡、AIモデルの学習に使用したりしません。Google APIから取得した情報の利用・他のサービスへの移転には、Google API Services User Data PolicyのLimited Use要件を遵守します。

保存と削除

通常は直近7日の日次分と4週の週次分を保持し、正常な新規バックアップと復元確認の後に古い保管分を順次整理します。削除された暗号化ファイルがGoogle Driveのゴミ箱に一定期間残る場合があります。Googleアカウントの接続設定から連携を解除できます。保管済みファイルの削除は運営者がGoogle Driveで行えます。
